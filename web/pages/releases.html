v0.3.0 - 7x more, 310x faster

September 4, 2026

In total, the size removed has gone up roughly 7x, now hitting a typical range of ~15-40%. For context, this now means a large 20mb creation could have ~5-9mb's shaved off.

Even while doing way more, this version is faster, way faster, processing time is down ~99.7% overall compared to the old version.

This was done by throwing out the DOM parser entirely, replacing it with a raw single-pass scan that cuts down on memory and time complexity.

Whats left is mostly the hell of manually filling in the lists of what blocks can have what done to them.
