v0.3.0 - 7x more, 310x faster

September 4, 2026

Size reduction is now roughly 7x higher, typically ~10-40%.
A 20 MB creation can now have ~5–9 MB shaved off.

Processing time is down ~99.7% overall while doing substantially more.

The DOM parser is gone entirely, replaced with a raw single-pass scan that cuts down both memory and processing time.
